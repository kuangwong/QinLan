# 拾日 · 网页交互原型

根据 [PLAN.md](../PLAN.md) 制作的第一轮界面与流程验证版本，使用 React、TypeScript、Vite。

## 直接体验

用 Chrome、Edge、Firefox 或 Safari 打开本目录的 **`prototype.html`**，无需安装依赖、启动服务器或联网。请在浏览器中打开文件，而非编辑器的 HTML 源码视图。

原型包含三个页面：

- **我的待办**：新建、编辑、完成、恢复、删除，按负责人、状态、关键词筛选，按截止时间排序；个人清单和共享清单。
- **名字灵感**：完整名称抽取、2–3 个有序词组组合；管理个人词库，粘贴文本或导入 UTF-8 TXT，去空行、去重，生成后自行决定是否保存。
- **名字日历**：按月浏览，查看同日多条记录，删除自己的记录，将名称与日期分享到共享清单，切换个人或共享清单视角。

点击左下角头像，可在「林小满」「陈一舟」「许知夏」三个演示成员之间切换。可在清单中体验邀请、确认加入、撤销邀请、成员移除、所有权转让、退出和删除。成员退出或被移除时，其未完成待办改为未分配。

数据保存在浏览器 localStorage 中，刷新可继续使用；清除站点数据可恢复初始示例。通过本地服务打开时，同源标签页会同步本地数据；不同浏览器、设备、文件副本之间不共享数据。文件模式的存储行为由浏览器决定，建议始终使用同一浏览器、同一文件路径。示例日期按第一次打开时的本地日期初始化。

## 工程开发

需要 Node.js 22 或更新版本及 pnpm 11.25.0。在本目录执行；工程附带 pnpm 锁文件，并仅允许 esbuild 运行依赖构建脚本。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

默认访问 `http://localhost:5173`。Vite 监听 `0.0.0.0`，需要局域网预览时访问该电脑的局域网 IP 与实际启动端口。

```bash
pnpm build
pnpm test
```

构建同时生成 `dist/` 和独立的 `prototype.html`。修改源文件后重新构建，才能更新单文件原型。测试使用 Node test runner 与 Happy DOM 验证构建后的实际界面流程。

## 原型范围

这是本地交互原型，**未实现真实注册登录、Fastify 后端、PostgreSQL、跨设备联网协作、服务端权限校验、版本冲突处理或系统通知**。演示账号和邀请码仅用于体验界面流程，不能作为安全机制。当前应用内到期列表可通过右上角铃铛查看。

名字生成不调用 AI 或外部服务。保存的记录独立保留名称、来源库名称、生成模式、本地归档日期和 UTC 保存时间，编辑或删除词库不会改变历史。待办与名字功能独立，保存或分享名字不会自动创建待办。

单文件原型已通过 Happy DOM 交互测试；实际浏览器的视觉与响应式表现仍需在浏览器中确认。
