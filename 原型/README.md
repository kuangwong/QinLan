# 拾日 · 网页客户端

按 [PLAN.md](../PLAN.md) 实现的 React、TypeScript、Vite 网页客户端。默认入口为真实账号与联网模式；登录页也提供独立的本地演示。

## 联网运行

先按 [后端说明](../server/README.md) 启动 PostgreSQL、迁移并运行协作服务。需要 Node.js 22+ 与 pnpm 11.25.0，在本目录执行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://localhost:5173`，注册或登录。连接设置留空，Vite 将 `/api` 代理到 `http://127.0.0.1:3000`。也可用 seed 创建的 `xiaoman` / `yizhou` 和自行配置的密码登录。使用两个浏览器会话验证协作；不同标签页可分别登录不同账号。

网页开发服务监听 `0.0.0.0`。局域网其他设备访问 `http://电脑IP:5173` 时，连接设置仍可留空，浏览器通过电脑上的 Vite 代理连接后端。直接填写其他服务地址时，须提供完整 HTTP/HTTPS 地址并在后端配置实际网页来源的 `CORS_ORIGINS`；HTTPS 网页须连接 HTTPS 服务。正式部署见 [Docker / HTTPS 交付](../deployment/README.md)。

## 已有功能

- 待办创建、编辑、完成、恢复和删除，个人及共享清单、负责人和状态筛选、关键词搜索、截止时间排序。
- 七天邀请码预览与确认加入、撤销、成员移除与退出、所有权转让及删除清单；后端校验权限与版本。
- 完整名称抽取、2–3 个有序词组组合；个人词库创建、编辑、删除，粘贴或导入 UTF-8 TXT，去空行与重复项。
- 手动保存名字、同日多条历史、固定本地归档日期及 UTC 保存时间、按月浏览、分享及撤回；删除词库不改变历史。
- 进入页面、切换视角、回到前台、手动和操作后刷新；查看共享清单及共享日历时每 30 秒刷新。
- 网络失败保留输入；版本冲突需确认载入最新内容；会话过期重新登录保留已挂载表单；保存结果不确定时先刷新确认。
- 应用内到期列表与浏览器通知授权入口。通知需页面保持打开及浏览器支持与授权，不保证关闭页面后提醒。局域网 HTTP 可能不支持通知和自动复制邀请码，可手动复制。

网页登录令牌保存在当前标签页的 `sessionStorage`，不写入本地演示的 `localStorage`；退出会撤销当前服务器会话。存储不可用时仅在内存中保持登录，并提示刷新后需要重新登录。共享任务只能分配给当前清单成员；名字与任务保持独立。

## 无服务体验

在浏览器打开 `prototype.html`，点击「先体验本地演示」，即可使用不依赖服务的界面演示。演示包含林小满、陈一舟、许知夏三个身份，数据保存在浏览器 `localStorage`；与真实账号数据独立，不上传、不跨设备同步。演示邀请码仅用于模拟流程。

直接从文件登录真实服务受浏览器对 `file:` 来源及 CORS 的限制，建议联网使用 Vite 或正式 HTTPS 站点。

## 构建与后续验证

```bash
pnpm build
# 用户当前要求暂不测试；具备环境后再执行：
pnpm test
```

构建进行 TypeScript 检查、生成 `dist/` 并重新生成 `prototype.html`；不要手工编辑生成文件。`pnpm preview` 可预览构建产物，默认沿用本地后端代理。

现有 `tests/prototype.test.mjs` 使用 Happy DOM 验证生成页面中的本地演示；后端测试和鸿蒙业务层测试见各自目录。联网双会话、浏览器通知及桌面/手机视觉表现仍需具备环境时单独验收。本轮未执行测试。
