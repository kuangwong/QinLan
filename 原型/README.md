# 拾日 · 网页客户端

根据 [PLAN.md](../PLAN.md) 开发的 React、TypeScript、Vite 网页客户端。默认是联网模式，连接 [Fastify/PostgreSQL 服务](../server/README.md)；也可以在内置的本地演示模式中体验界面流程。

## 直接体验

用 Chrome、Edge、Firefox 或 Safari 打开本目录的 **`prototype.html`**，无需安装依赖或启动服务器。页面默认显示联网登录页；**不启动后端时，请点“先体验本地演示”**。直接双击文件只保证演示模式可用：浏览器的 `file://` 源无法使用默认 CORS 配置连接后端。

演示模式包含三个页面：

- **我的待办**：新建、编辑、完成、恢复、删除，按负责人、状态、关键词筛选，按截止时间排序；个人清单和共享清单。
- **名字灵感**：完整名称抽取、2–3 个有序词组组合；管理个人词库，粘贴文本或导入 UTF-8 TXT，去空行、去重，生成后自行决定是否保存。
- **名字日历**：按月浏览，查看同日多条记录，删除自己的记录，将名称与日期分享到共享清单，切换个人或共享清单视角。

点击左下角头像，可在「林小满」「陈一舟」「许知夏」三个演示成员之间切换。可在清单中体验邀请、确认加入、撤销邀请、成员移除、所有权转让、退出和删除。成员退出或被移除时，其未完成待办改为未分配。

演示数据保存在浏览器 localStorage 中，刷新可继续使用；清除站点数据可恢复初始示例。通过本地服务打开时，同源标签页会同步本地数据；不同浏览器、设备、文件副本之间不共享数据。示例日期按第一次打开时的本地日期初始化。

## 联网模式

1. 按 [服务端说明](../server/README.md) 启动 PostgreSQL、迁移、seed 和 `pnpm dev`。
2. 在本目录执行 `pnpm dev`，打开 `http://localhost:5173`。Vite 已把 `/api` 代理到 `http://127.0.0.1:3000`。
3. 注册新账号，或使用 seed 生成的 `xiaoman` / `yizhou` 及自行设置的 `DEMO_PASSWORD`。
4. 需要验证协作时，用两个浏览器标签页或两个浏览器配置分别登录两个账号。

联网模式的账号、清单、权限和冲突检查都由服务端执行。页面进入、回到前台、操作后和手动刷新时同步；打开共享清单的任务或日历视角时每 30 秒刷新。请求失败保留表单输入；版本冲突提供“载入最新内容”，自动刷新不会清掉这个入口。连接地址与账号数据保存在 sessionStorage；关闭标签页后需要重新登录。

其他设备访问时，Vite 监听 `0.0.0.0`；若要直接连后端，在登录页填写 `http://电脑局域网IP:3000`，并确保 `server/.env` 的 `HOST=0.0.0.0`、`CORS_ORIGINS` 允许网页来源。正式环境应使用 HTTPS 和同源反向代理。

## 工程开发

需要 Node.js 22 或更新版本及 pnpm 11.25.0。在本目录执行；工程附带 pnpm 锁文件，并仅允许 esbuild 运行依赖构建脚本。

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm test
```

`pnpm build` 同时生成 `dist/` 和独立的 `prototype.html`。`pnpm test` 会先执行构建，再用 Node test runner 与 Happy DOM 验证：

- 构建后的单文件演示流程（5 项）；
- 联网登录、任务创建、409 冲突恢复、保存名字、日历分享、邀请生成与加入（4 项，使用确定性假 API）。

真实服务端契约由 `server/pnpm test` 的真实 PostgreSQL 测试保证；浏览器视觉和响应式表现仍需人工确认。

## 边界

- 词库每组最多 2000 个候选，每个候选最多 100 字符；合法三组拼接结果最多 300 字符，记录字段仍兼容历史 900 字符。旧版超限词库仍可读取，编辑保存前需要先缩减。
- 联网模式不提供离线编辑；演示模式的数据不会上传。
- 浏览器通知只在页面打开且用户授权时可用；关闭页面后不承诺提醒。
- 待办与名字功能独立，保存或分享名字不会自动创建待办。
